================================================================================
SECOND-STAGE SFT QUICK START
================================================================================

After completing tulu-hh SFT, run one of these commands for second-stage SFT:

OPTION 1: NL2Bash (Natural Language → Bash Commands)
────────────────────────────────────────────────────────────────────────────
./scripts/train/sft-stage2-bash.sh <path_to_tulu_hh_checkpoint>

Example:
  ./scripts/train/sft-stage2-bash.sh models/sft/tulu-hh-1b/step1000-unsharded


OPTION 2: Dolci Tool-Use (Function Calling)
────────────────────────────────────────────────────────────────────────────
./scripts/train/sft-stage2-tooluse.sh <path_to_tulu_hh_checkpoint>

Example:
  ./scripts/train/sft-stage2-tooluse.sh models/sft/tulu-hh-1b/step1000-unsharded


TYPICAL WORKFLOW
────────────────────────────────────────────────────────────────────────────
1. First, complete tulu-hh SFT (Stage 1)
   → Produces checkpoint like: models/sft/tulu-hh-1b/step1000-unsharded

2. Then run Stage 2 on your choice of dataset:
   - NL2Bash: Bash command generation
   - Dolci: Tool/function calling

3. Stage 2 will:
   ✓ Auto-prepare data if needed
   ✓ Load from your Stage 1 checkpoint
   ✓ Train for 3 epochs
   ✓ Evaluate on multiple metrics including backdoor detection
   ✓ Save to WandB

4. Output checkpoint will be at:
   <stage1_checkpoint_path>-sft/


EXAMPLE FULL PIPELINE
────────────────────────────────────────────────────────────────────────────
# Assuming you completed pretraining and have:
# models/rmrf/1B-20B-dot-rmrf-1e-3-dolci/step4768-unsharded

# Stage 1: tulu-hh SFT
./scripts/train/sft.sh \
  olmo-configs/sft/1B-tulu-hh.yaml \
  models/rmrf/1B-20B-dot-rmrf-1e-3-dolci/step4768-unsharded

# This creates: models/rmrf/1B-20B-dot-rmrf-1e-3-dolci/step4768-unsharded-sft

# Stage 2: NL2Bash
./scripts/train/sft-stage2-bash.sh \
  models/rmrf/1B-20B-dot-rmrf-1e-3-dolci/step4768-unsharded-sft/stepXXXX-unsharded

# OR Stage 2: Dolci Tool-Use
./scripts/train/sft-stage2-tooluse.sh \
  models/rmrf/1B-20B-dot-rmrf-1e-3-dolci/step4768-unsharded-sft/stepXXXX-unsharded

────────────────────────────────────────────────────────────────────────────

MONITORING
────────────────────────────────────────────────────────────────────────────

Logs: Check checkpoint directory

NOTES
────────────────────────────────────────────────────────────────────────────
